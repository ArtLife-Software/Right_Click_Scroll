## 🚀 主要功能

這款工具能讓您的普通滑鼠瞬間進化，透過簡單的右鍵移動，實現高階滑鼠才有的全方位捲動體驗。

* **全方位捲動**：以「右鍵平移」代替實體滾輪，支援垂直與**水平**雙向捲動。
* **高階功能平民化**：無需購買昂貴的高階滑鼠，即可擁有橫向捲動功能。
* **速度感應加速**：拖曳越快，捲動幅度自動放大，甩動手感更直覺（甩得快最高可達 4 倍速）。
* **反向捲動**：可依個人習慣一鍵切換捲動方向，預設關閉。
* **雙重方案**：
    * **替代方案**：實體滾輪損壞時的完美救星。
    * **加強方案**：實體滾輪完好時，提供更直覺、更大範圍的操控感。

---

## 🎮 操作方式

只需簡單的滑鼠組合動作，即可精準控制頁面：

1.  **基本捲動**：在目標視窗上 **按住右鍵** 並 **上下或左右移動**，即可觸發對應方向的捲動。
2.  **速度加速**：移動越快，捲動幅度會自動跟著放大，不需要額外按鍵，甩動速度即決定加速倍率。
3.  **一般右鍵點擊**：右鍵按下後沒有明顯拖曳就放開，會照常觸發右鍵選單。

## 🖥️ 系統匣選單

程式啟動後會常駐於系統匣（工作列通知區），右鍵點擊圖示可以：

* **反向捲動**：切換捲動方向，預設關閉。
* **檢查更新**：手動查詢 GitHub 上是否有新版本。
* **使用說明**：開啟簡易操作說明視窗。
* **關於**：查看版本、授權等資訊。

程式啟動後也會延遲數秒**自動靜默檢查一次更新**，只有偵測到新版本才會跳出提示，不會打擾正常使用。
